# Brand Positioning

Sayang Intan Berlian คือผู้เชี่ยวชาญด้านการออกแบบและผลิตเครื่องประดับ Heritage
Luxury Thai--Malay โดยเน้นงาน **Handmade**, **Custom Made** และ **Unique
Design** ที่สะท้อนเอกลักษณ์ของลูกค้าแต่ละคน

เราเชื่อว่าเครื่องประดับไม่ควรเป็นเพียงของตกแต่ง
แต่ควรเป็นชิ้นงานที่สามารถส่งต่อคุณค่าและเรื่องราวจากรุ่นสู่รุ่น

# เอกลักษณ์การออกแบบ

แรงบันดาลใจหลักมาจากศิลปะไทยและมลายูที่สืบทอดภายในครอบครัวมาตั้งแต่รุ่นทวด

แนวทางการออกแบบ

-   Antique
-   Vintage
-   Handmade
-   Heritage
-   Family Heirloom

สามารถออกแบบเครื่องประดับที่มีเรื่องราวของครอบครัว (Heirloom Jewelry)

------------------------------------------------------------------------

# ขั้นตอนการให้บริการ

1.  ลูกค้าแจ้งความต้องการ
2.  ให้คำปรึกษาออนไลน์ หรือเดินทางไปพบลูกค้า
3.  ออกแบบให้เหมาะกับงบประมาณ
4.  จัดทำ Sketch หรือ 3D
5.  ปรับแก้แบบได้ไม่จำกัดก่อนเริ่มผลิต
6.  วางมัดจำอย่างน้อย 50%
7.  ผลิตภายใน 2 สัปดาห์ -- 2 เดือน (ขึ้นอยู่กับความซับซ้อนของงาน)
8.  ตรวจสอบคุณภาพ (QC)
9.  จัดส่งพร้อมประกันสินค้า

------------------------------------------------------------------------

# การรับประกัน

-   รับประกันงานผลิต 6 เดือนหลังรับสินค้า
-   ขัดทำความสะอาดฟรี (ตามเงื่อนไขการรับประกัน)
-   ปรับไซซ์ฟรี (ตามเงื่อนไข)
-   ใส่พลอยหรือเพชรที่หลุดฟรี (ตามเงื่อนไข)
